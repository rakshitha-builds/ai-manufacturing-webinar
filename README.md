
# AI-Powered Manufacturing: Building the Factory of Tomorrow

A premium, fully responsive landing page for a live online webinar on AI in manufacturing. It is a conversion-focused sales page with a countdown, agenda, pricing and a validated registration form.

**Live demo:** https://rakshitha-builds.github.io/ai-manufacturing-webinar/

> **Demo notice:** The speaker (Dr. Arjun Mehta) is a fictional profile and the registration form is a demonstration flow. No payment is processed, no data is sent anywhere and no booking is created.

## Features

- Hero with live countdown to December 12, 2026, 10:00 AM IST
- Sticky navbar with scroll-spy, blur-on-scroll and animated mobile menu
- Sections: challenges, what you'll learn, agenda timeline, speaker, audience, pricing, FAQ, final CTA
- Registration form with required-field, email and Indian mobile validation, loading state and duplicate-submit protection
- Animated FAQ accordion, scroll reveals and hover effects
- Respects `prefers-reduced-motion`
- Responsive from 375px mobile to desktop, with semantic and accessible markup

## Tech stack

React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide React

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm run preview  # preview the build
```
