# AI-Powered Manufacturing Webinar Landing Page
React + TypeScript + Tailwind CSS + Framer Motion + Lucide React (Vite).

PowerShell:
    npm install
    npm run dev       # http://localhost:5173
    npm run build     # type-check + production build

Registration is a demo flow: no payment, no backend. Speaker is fictional.
Replace `src/components/FactoryVisual.tsx` with a real photo (put it in `public/` and use <img loading="lazy">) if you have one.
